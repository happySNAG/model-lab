WHAT THIS PROGRAM DOES

Cernum is a benchmarking environment for language models: local models that run
on this computer through Ollama, and frontier models reached through the command
line tools or API keys you configure yourself. It sends fixed, sealed benchmark
tasks to the models you choose, judges the results with deterministic rules, and
keeps every result on this computer as permanent evidence.

WHERE YOUR DATA GOES

Local models stay local: Cernum talks to Ollama on this computer over loopback
only. If you configure a remote provider, the benchmark task content that
provider needs for inference is sent to it, under that provider's own terms;
Cernum tells you before any campaign that does this runs. Cernum itself has no
telemetry, no update check and no account, never reads a tool's stored login,
and never installs a language model unless you explicitly ask it to download
one. Benchmark results are evidence for your own decisions; Cernum changes
nothing about how any model is used anywhere.

Uninstalling Cernum removes the application but keeps your evidence store
(under your user application data folder), so your history is never silently
deleted.
